PRACTICAL 1A: Matrix Addition, Multiplication, and Scalar Operations

1. Aim

To understand and implement fundamental matrix operations (addition, scalar multiplication, and matrix multiplication) using fundamental Python constructs, incorporating a menu-driven interface and dynamic input handling for matrices of any arbitrary size.

2. Comprehensive Theory

Matrices are rectangular arrays of numbers arranged in rows and columns. They are foundational to linear algebra and widely used in computational mathematics and machine learning.

  • Matrix Addition: The addition of two matrices is performed element by element. Two matrices can only be added if they are of the exact same order (i.e., they have the same number of rows \(m\) and columns \(n\)). If \(A = [A_{ij}]\) and \(B = [B_{ij}]\), their sum \(C = A + B\) is given by:

\[C_{ij} = A_{ij} + B_{ij}\]

  • Scalar Multiplication: When a matrix is multiplied by a scalar (a single real number \(k\)), every individual element inside the matrix is multiplied by that scalar.

\[C_{ij} = k \cdot A_{ij}\]

  • Matrix Multiplication: The product of two matrices is calculated by taking the dot product of the rows of the first matrix with the columns of the second matrix. Matrix multiplication is only defined if the number of columns in the first matrix (\(A\)) strictly equals the number of rows in the second matrix (\(B\)). If \(A\) is an \(m \times n\) matrix and \(B\) is an \(n \times p\) matrix, their product \(C = AB\) is an \(m \times p\) matrix defined by:

\[C_{ij} = \sum_{k=1}^{n} A_{ik} \cdot B_{kj}\]

3. Program Logic

In pure Python, matrices are represented as nested lists (a list containing sub-lists, where each sub-list is a row). The core mathematical functions remain isolated from the input/output logic to ensure modularity.

  • Dimension Checking: Before performing operations, the program calculates the dimensions using len(matrix) for rows and len(matrix[0]) for columns. If constraints are not met, it uses the raise ValueError construct to cleanly halt the invalid operation.

  • Zero Matrix Initialization: We use list comprehension [[0 for _ in range(cols)] for _ in range(rows)] to dynamically create an empty grid of the correct size to store our answers.

  • Nested Loops:

  • Addition and Scalar Multiplication require a double loop: an outer loop i traversing rows, and an inner loop j traversing columns.

  • Matrix Multiplication requires a triple loop: i for the rows of \(A\), j for the columns of \(B\), and a third inner loop k_idx to iterate through the matching inner dimensions and compute the cumulative dot product sum.

  • Dynamic Input: The program takes runtime input from the user to define arbitrary row and column counts. It then uses input().split() within a loop, converting the string inputs into integers and appending them to create custom matrices of any size.

  • Menu-Driven Execution: A while True loop creates an interactive menu. User choices trigger specific operations using an if-elif structure, combined with try-except blocks to catch and gracefully display dimension-related ValueError exceptions without crashing.

PRACTICAL 1B: Eigenvalue and Eigenvector Calculation for 2x2 Matrices

1. Aim

To understand and implement eigenvalue and eigenvector calculation for \(2 \times 2\) matrices using fundamental Python constructs.

2. Theory

In linear algebra, an eigenvector is a non-zero vector that changes by only a scalar factor when a linear transformation is applied to it. The corresponding scalar factor is the eigenvalue.

Mathematically, for a square matrix \(A\), if there exists a vector \(v\) and a scalar \(\lambda\) such that:

\[A v = \lambda v\]

Then \(v\) is the eigenvector and \(\lambda\) is the eigenvalue.

For a \(2 \times 2\) matrix \(A = \begin{bmatrix} a & b \\ c & d \end{bmatrix}\), we find the eigenvalues by solving the characteristic equation:

\[\det(A - \lambda I) = 0\]

This expands to a quadratic equation:

\[\lambda^2 - \text{Tr}(A)\lambda + \det(A) = 0\]

Where:

  • Trace (Tr) \(= a + d\) (the sum of the main diagonal).
  • Determinant (det) \(= ad - bc\).

Using the quadratic formula, the two eigenvalues (\(\lambda_1\) and \(\lambda_2\)) are:

\[\lambda = \frac{\text{Tr}(A) \pm \sqrt{\text{Tr}(A)^2 - 4\det(A)}}{2}\]

Once the eigenvalues are found, the corresponding eigenvectors are determined by substituting \(\lambda\) back into the equation \((A - \lambda I)v = 0\) and solving for the components of \(v\).

3. Program Logic

The provided code strictly calculates the eigenvalues and eigenvectors for a \(2 \times 2\) matrix without relying on external mathematical libraries like NumPy (except for math.sqrt).

  • Element Extraction: The matrix elements are extracted into individual variables \(a, b, c,\) and \(d\) for readable mathematical operations.
  • Eigenvalue Calculation: The determinant and trace are computed, and the quadratic formula is applied directly to find the two eigenvalues, storing them in a list.
  • Eigenvector Calculation: The program calculates four specific vector combinations. By assuming the first component of the vector is \(1\) (\(x=1\)), the second component (\(y\)) is calculated as \((\lambda - a)/b\). Conversely, it also calculates alternative vectors assuming the second component is \(1\), demonstrating different proportional scalings of the eigenvectors.
  • User Input: A loop collects two rows of space-separated integers from the user, dynamically building the \(2 \times 2\) list structure.

4. Step-by-Step Algorithm

  1. Start.

  2. Define compute_eigen_2x2(matrix):

    • Extract elements \(a, b, c, d\) from the \(2 \times 2\) nested list.
    • Calculate det as \(a \cdot d - b \cdot c\).
    • Calculate trace as \(a + d\).
    • Compute lambda1 and lambda2 using the quadratic formula: \(\frac{\text{trace} \pm \sqrt{\text{trace}^2 - 4 \cdot \text{det}}}{2}\).
    • Construct the eigenvectors list containing four proportional vector combinations based on the extracted eigenvalues.
    • Return the lists of eigenvalues and eigenvectors.

  3. Main Execution: Initialize an empty matrix list.

  4. Loop 2 times, prompting the user to input 2 space-separated numbers. Parse these into integers and append the row to matrix.

  5. Call compute_eigen_2x2(matrix) and unpack the returned values.

  6. Print the two eigenvalues.

  7. Print the four calculated eigenvector coordinate pairs.

  8. Stop.

import math

def compute_eigen_2x2(matrix):
    a, b = matrix[0][0], matrix[0][1]
    c, d = matrix[1][0], matrix[1][1]

    # Calculate determinant and trace
    det = a * d - b * c
    trace = a + d

    # Calculate discriminant
    discriminant = trace**2 - 4 * det

    # Check if discriminant is negative
    if discriminant < 0:
        print("The discriminant is negative.")
        print("The matrix has complex eigenvalues.")
        return None, None

    # Calculate eigenvalues
    eigenvalues = [
        (trace + math.sqrt(discriminant)) / 2,
        (trace - math.sqrt(discriminant)) / 2
    ]

    # Calculate eigenvectors
    eigenvectors = []

    for eigenvalue in eigenvalues:

        if b != 0:
            # Set x = 1
            eigenvector = [
                1,
                (eigenvalue - a) / b
            ]

        elif c != 0:
            # Set y = 1
            eigenvector = [
                (eigenvalue - d) / c,
                1
            ]

        else:
            # Matrix is diagonal
            if eigenvalue == a:
                eigenvector = [1, 0]
            else:
                eigenvector = [0, 1]

        eigenvectors.append(eigenvector)

    return eigenvalues, eigenvectors

PRACTICAL 1C: Gaussian Elimination from Scratch

1. Aim

To solve a system of linear equations by implementing the Gaussian elimination algorithm from scratch inside a reusable function, incorporating dimensional validation, forward elimination, and back substitution.

2. Theory

Gaussian Elimination is a systematic algebraic algorithm used to solve systems of linear equations, find the rank of a matrix, or calculate the inverse of an invertible square matrix.

A system of \(n\) linear equations with \(n\) variables can be represented in matrix form as:

\[Ax = b\]

Where:

  • \(A\) is the \(n \times n\) coefficient matrix.
  • \(x\) is the column vector of unknown variables.
  • \(b\) is the column vector of constants.

The algorithm solves the system in two major phases:

  • Forward Elimination: Applying elementary row operations to transform the coefficient matrix \(A\) into an Upper Triangular Matrix (where all elements below the main diagonal are zero). Simultaneously, these operations are applied to the constant vector \(b\).
  • Back Substitution: Once the matrix is in upper triangular form, the bottom-most equation contains only one variable, which can be solved directly. This known value is substituted backwards into the equation above it to find the next variable, repeating until all variables are solved.

3. Program Logic

The provided code solves the system by combining both \(A\) and \(b\) transformations within the same loops.

  • Diagonal Normalization (Pivoting): Instead of standard elimination, this specific implementation simplifies the matrix further by dividing the entire current row by the diagonal element (pivot = A[i][i]). This forces the main diagonal of the matrix to become exactly \(1\), which significantly simplifies the later back substitution step.
  • Forward Elimination Loop: An outer loop i selects the current pivot row. The inner loop k iterates through all rows below the pivot row. It calculates a factor and subtracts factor * row[i] from row[k] to introduce zeros below the diagonal.
  • Back Substitution Loop: The loop range(n-1, -1, -1) traverses the matrix from the last row up to the first. Because the diagonal elements were forced to \(1\), calculating the unknown variable simply requires subtracting the products of the known variables and their coefficients from the modified constant vector \(b\).
  • Input Collection: The program uses a dynamically sized loop based on user input to collect the matrix \(A\) and vector \(b\).

4. Step-by-Step Algorithm

  1. Start.

  2. Define gaussian_elimination(A, b):

    • Determine the size of the system \(n\) from the length of \(b\).

    • Forward Elimination Phase:

    • Loop i from \(0\) to \(n-1\).

    • Identify the pivot element \(A_{ii}\).

    • Divide the entire row \(i\) in \(A\) and the corresponding element in \(b\) by the pivot to make the diagonal element \(1\).

    • Loop k from \(i+1\) to \(n-1\) (all rows below the pivot).

    • Find the multiplier factor \(= A_{ki}\).

    • Update row k: \(A_{kj} = A_{kj} - (\text{factor} \cdot A_{ij})\). Update \(b_k\) accordingly.

    • Back Substitution Phase:

    • Initialize a solution array x of size \(n\) with zeros.

    • Loop i backwards from \(n-1\) down to \(0\).

    • Set \(x_i = b_i\).

    • Subtract the known values: \(x_i = x_i - \sum (A_{ij} \cdot x_j)\) for all \(j > i\).

    • Return the solution array x.

  3. Main Execution: Prompt the user for the matrix size size.

  4. Initialize empty lists A and b.

  5. Loop size times, prompting the user for a space-separated row of \(A\) and a single constant for \(b\).

  6. Call gaussian_elimination(A, b) and print the returned list.

  7. Stop.

def gaussian_elimination(A, b):
    n = len(b)

    # Forward elimination
    for i in range(n):
        # Make the diagonal element 1
        pivot = A[i][i]
        for j in range(n):
            A[i][j] /= pivot
        b[i] /= pivot

        # Make all rows below this one 0 in the current column
        for k in range(i+1, n):
            factor = A[k][i]
            for j in range(i, n):
                A[k][j] -= factor * A[i][j]
            b[k] -= factor * b[i]

    # Back substitution
    x = [0] * n

PRACTICAL 2C: Central Limit Theorem

1. Aim

To demonstrate the Central Limit Theorem by plotting the sample mean distributions for a given population and sample size, utilizing random sampling and graphical overlay.

2. Comprehensive Theory

The Central Limit Theorem (CLT) is one of the most fundamental theorems in statistics and probability theory. It states that the sampling distribution of the sample mean approaches a normal distribution as the sample size gets larger — regardless of the shape of the original population distribution.

Mathematically, if you draw sufficiently large samples (conventionally \(n \ge 30\)) from a population with a mean \(\mu\) and a standard deviation \(\sigma\), the distribution of those sample means (\(\bar{X}\)) will approximate a normal distribution.

The properties of this sampling distribution of the mean are:

  • The mean of the sample means will be approximately equal to the population mean: \(\mu_{\bar{X}} \approx \mu\)
  • The standard deviation of the sample means (called the Standard Error) will be equal to the population standard deviation divided by the square root of the sample size: \(\sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}}\)

This theorem is practically powerful because it allows statisticians to use normal probability calculations to make inferences about population parameters even when the underlying population is not normally distributed (e.g., uniformly distributed, heavily skewed, etc.).

3. Program Logic

The code proves the CLT via a Monte Carlo simulation approach.

  • Non-Normal Population: First, the program intentionally creates a completely flat, non-normal population of 100,000 items using np.random.uniform(0, 1).
  • Repeated Sampling: It sets a sample size of \(n=30\). Using a list comprehension, it randomly selects 30 items from the uniform population, calculates their mean, and repeats this process 1,000 times.
  • Histogram Density Plotting: It plots these 1,000 means using plt.hist. The crucial parameter density=True normalizes the histogram so that the total area under the bars equals \(1\). This allows the histogram to be compared directly against a mathematical probability density function (PDF).
  • Theoretical Overlay: The program calculates the empirical mean and standard deviation of the generated sample means. Using these statistics, it generates a perfectly smooth, theoretical Normal Distribution curve (norm.pdf) and plots it in red over the histogram to visually verify if the sample means truly formed a bell curve.

PRACTICAL 3A: Perform Large Sample Test for Single Mean (Z-test)

1. Aim

To perform a Large Sample Test for a Single Mean (Z-test) by formulating a reusable Python function that computes the Z-score and p-value to accept or reject a null hypothesis based on a specified level of significance.

2. Comprehensive Theory

In inferential statistics, Hypothesis Testing is a method used to decide whether the data at hand sufficiently support a particular hypothesis. A Z-test is a statistical test used to determine whether two population means are different, provided the variances are known and the sample size is large (\(n \ge 30\)). If the population standard deviation is unknown, the sample standard deviation can be used as an estimate for large samples.

The test compares two hypotheses:

  • Null Hypothesis (\(H_0\)): Assumes that there is no significant difference between the sample mean and the population mean (\(\bar{x} = \mu\)).
  • Alternative Hypothesis (\(H_1\)): Assumes there is a significant difference. It can be two-tailed (\(\bar{x} \neq \mu\)), right-tailed (\(\bar{x} > \mu\)), or left-tailed (\(\bar{x} < \mu\)).

The Test Statistic (Z-score) is calculated as:

\[Z = \frac{\bar{x} - \mu}{\frac{\sigma}{\sqrt{n}}}\]

Where:

  • \(\bar{x}\) = Sample mean
  • \(\mu\) = Population mean
  • \(\sigma\) = Population standard deviation (or sample standard deviation \(s\) if \(\sigma\) is unknown)
  • \(n\) = Sample size

The p-value represents the probability of observing test results at least as extreme as the results actually observed, assuming that the null hypothesis is correct. If the p-value is less than or equal to the significance level (\(\alpha\), usually \(0.05\)), we reject the Null Hypothesis.

3. Program Logic

The program defines a flexible z_test function utilizing the numpy and scipy.stats.norm libraries.

  • Parameter Handling: The function accepts the sample data, population mean, standard deviation, significance level, and hypothesis type. If population_std is not provided (None), it estimates it by calculating the sample standard deviation using np.std with ddof=1 (Bessel’s correction for an unbiased estimator).

  • Z-score Computation: It calculates the standard error (\(\sigma / \sqrt{n}\)) and applies the Z-score formula.

  • Conditional p-value Evaluation: Depending on the alternative parameter:

  • 'two-sided': Calculates the probability in both tails by multiplying the survival function (norm.sf) of the absolute Z-score by 2.

  • 'greater': Uses the survival function (norm.sf) to find the area to the right of the Z-score.

  • 'less': Uses the cumulative distribution function (norm.cdf) to find the area to the left of the Z-score.

  • Result Dictionary: The function packages all computed statistics and a definitive conclusion (“Reject H0” or “Fail to reject H0”) into a Python dictionary for clean output extraction.

4. Step-by-Step Algorithm

  1. Start.

  2. Define z_test function:

    • Accept parameters: sample, population_mean, population_std, significance_level, alternative.
    • Convert sample to a NumPy array.
    • Calculate sample size n and sample_mean.
    • If population_std is None, calculate it from the sample using ddof=1.
    • Calculate z_score \(= (\text{sample\_mean} - \text{population\_mean}) / (\text{population\_std} / \sqrt{n})\).

  3. Calculate p-value based on alternative:

    • If 'two-sided': p_value = 2 * norm.sf(abs(z_score)).
    • If 'greater': p_value = norm.sf(z_score).
    • If 'less': p_value = norm.cdf(z_score).
    • If invalid, raise ValueError.

  4. Evaluate Hypothesis:

    • If p_value < significance_level, set conclusion to 'Reject H0'.
    • Else, set conclusion to 'Fail to reject H0'.

  5. Return Dictionary: Return all calculated metrics and the conclusion.

  6. Main Execution:

    • Define a sample array, population_mean (50), significance_level (0.05), and alternative (‘greater’).
    • Call z_test and store the returned dictionary in result.
    • Print z_score, p_value, means, standard deviation, and the Conclusion formatted to 4 decimal places.

  7. Stop.

import numpy as np
from scipy.stats import norm

def z_test(sample, population_mean, population_std=None, significance_level=0.05, alternative='two-sided'):
    sample = np.array(sample)
    n = len(sample)
    sample_mean = np.mean(sample)

    if population_std is None:
        population_std = np.std(sample, ddof=1)

    z_score = (sample_mean - population_mean) / (population_std / np.sqrt(n))

    # Calculate p-value based on the alternative hypothesis
    if alternative == 'two-sided':
        p_value = 2 * norm.sf(np.abs(z_score))   # 2 * (1 - norm.cdf(np.abs(z_score)))
    elif alternative == 'greater':
        p_value = norm.sf(z_score)   # or 1 - norm.cdf(z_score)
    elif alternative == 'less':
        p_value = norm.cdf(z_score)
    else:
        raise ValueError("Invalid alternative hypothesis. Must be 'two-sided', 'greater', or 'less'.")

    return {
        'z_score': z_score,
        'p_value': p_value,
        'sample_mean': sample_mean,
        'population_mean': population_mean,
        'population_std': population_std,
        'Conclusion': 'Reject H0' if p_value < significance_level else 'Fail to reject H0'
    }

# Example usage

PRACTICAL 3D: Perform F-test for Variances (Small Samples)

1. Aim

To perform an F-test to compare the variances of two small samples using statistical Python libraries, determining whether two populations have significantly different levels of dispersion.

2. Comprehensive Theory

In statistics, the F-test for variances is used to determine if two populations have equal variances. This test is highly sensitive to the assumption that the data are drawn from a normal distribution. It is often a critical prerequisite for other statistical tests (like the two-sample t-test), which require the assumption of equal variances.

The test compares two hypotheses:

  • Null Hypothesis (\(H_0\)): \(\sigma_1^2 = \sigma_2^2\) (The variances of the two populations are equal).
  • Alternative Hypothesis (\(H_1\)): \(\sigma_1^2 \neq \sigma_2^2\) (The variances of the two populations are different).

The Test Statistic (F) is simply the ratio of the two sample variances:

\[F = \frac{S_1^2}{S_2^2}\]

By convention in many standard computational tests, we place the larger variance in the numerator. This forces the calculated \(F\)-ratio to be \(1\) or greater (\(F \ge 1\)), which simplifies the process of checking against the upper-tail critical values of the right-skewed F-distribution.

The shape of the F-distribution depends on two degrees of freedom:

  • \(df_1 = n_1 - 1\) (degrees of freedom for the numerator sample)
  • \(df_2 = n_2 - 1\) (degrees of freedom for the denominator sample)

3. Program Logic

The program defines a custom function f_test_variances to securely compute the F-statistic and its associated probabilities.

  • Variance Calculation: The raw lists are converted to NumPy float arrays. The unbiased sample variances are calculated using .var(ddof=1).

  • Numerator/Denominator Selection: An if-else block evaluates which sample has the larger variance. It assigns the larger variance to the numerator to ensure \(F \ge 1\). The degrees of freedom (\(df_1\) and \(df_2\)) are mapped corresponding to the numerator and denominator selections.

  • Probability Computations: It uses scipy.stats.f.

  • p-value: Because it is a two-tailed test, the p-value is calculated by taking the minimum of the upper or lower tail cumulative distribution function (CDF) and multiplying it by 2: 2 * min(cdf, 1-cdf).

  • Critical Value: The Percent Point Function (ppf, the inverse of the CDF) calculates the exact F-value at the upper tail cutoff (\(1 - \alpha/2\)).

  • Decision Logic: If the computed \(F\) statistic is strictly greater than the critical F-value, the Boolean reject flag evaluates to True.

from scipy.stats import f as f_dist

def f_test_variances(sample1, sample2, alpha=0.05):
    # Convert lists to NumPy arrays with float type
    s1 = np.asarray(sample1, dtype=float)
    s2 = np.asarray(sample2, dtype=float)

    # Calculate sample variances (ddof=1 for sample variance)
    var1, var2 = s1.var(ddof=1), s2.var(ddof=1)
    n1, n2 = len(s1), len(s2)

    # Place larger variance in the numerator so that F >= 1
    if var1 >= var2:
        F = var1 / var2
        df1, df2 = n1 - 1, n2 - 1
    else:
        F = var2 / var1
        df1, df2 = n2 - 1, n1 - 1

    # Calculate two-tailed p-value and critical value
    p_value = 2 * min(f_dist.cdf(F, df1, df2), 1 - f_dist.cdf(F, df1, df2))
    critical_value = f_dist.ppf(1 - alpha / 2, df1, df2)
    reject = F > critical_value

    return {
        "Variance 1": round(var1, 4),
        "Variance 2": round(var2, 4),
        "F-statistic": round(F, 4),
        "df1, df2": (df1, df2),
        "Critical F (alpha/2)": round(critical_value, 4),
        "p-value": round(p_value, 6),
        "Conclusion": "Reject H0 (variances differ)" if reject else "Fail to Reject H0 (variances equal)",
    }

PRACTICAL 4B: Calculate n-step Transition Probability for a Markov Chain

1. Aim

To calculate the n-step transition probability for a Markov Chain using matrix operations and to visually demonstrate the convergence of these probabilities to a steady-state distribution.

2. Comprehensive Theory

A Markov Chain is a stochastic model describing a sequence of events where the probability of each event depends only on the state attained in the previous event. This memoryless characteristic is known as the Markov Property.

The probabilities of moving from one state to another are represented by a Transition Matrix (\(P\)). If a system has \(k\) possible states, \(P\) is a \(k \times k\) square matrix where:

  • \(P_{ij}\) represents the probability of moving from state \(i\) to state \(j\) in one step.
  • The matrix is a Right Stochastic Matrix, meaning every entry is between \(0\) and \(1\) (\(0 \le P_{ij} \le 1\)), and the sum of probabilities in every single row must equal exactly \(1\) (\(\sum_j P_{ij} = 1\)).

The n-step Transition Probability: To find the probability of transitioning from state \(i\) to state \(j\) in exactly \(n\) steps, we rely on the Chapman-Kolmogorov equations. In matrix algebra, this is elegantly solved by multiplying the transition matrix by itself \(n\) times. Thus, the \(n\)-step transition matrix is simply \(P^n\).

Steady-State (Stationary) Distribution: For regular Markov Chains, as the number of steps \(n\) approaches infinity (\(n \to \infty\)), the matrix \(P^n\) converges. Every row becomes identical. This means the system reaches a long-term equilibrium where the initial starting state no longer influences the future probabilities.

3. Program Logic

The program utilizes numpy for linear algebra computations and matplotlib to visualize probability behaviors over time.

  • Validation (validate_transition_matrix): Before performing any math, the program strictly verifies that the input matrix is structurally sound. It checks if it is a 2D square matrix, verifies there are no negative numbers or values exceeding \(1\), and uses np.allclose(P.sum(axis=1), 1) to mathematically ensure every row sums to \(1\) (accounting for minor floating-point precision errors).
  • Matrix Exponentiation (n_step_transition_probability): Instead of writing manual loops for matrix multiplication, the program uses NumPy’s highly optimized np.linalg.matrix_power(P, n). This efficiently computes \(P^n\).
  • Iterative Observation: The program loops over a targeted list of steps [1, 2, 5, 10, 20], computing and printing the matrix at each stage so the user can observe the rows slowly becoming identical.
  • Visualization: The program calculates \(P^n\) for every step from \(1\) to \(20\). It extracts just the first row ([0])—which represents the probabilities assuming the system started in the “Sunny” state—and plots these values on a line graph to visually demonstrate how the probabilities stabilize over time.

PRACTICAL 4D: Simulate Higher Order Markov Chain

1. Aim

To simulate a second-order Markov Chain by generating synthetic sequential data, computing transition probabilities based on the previous two states, and utilizing these empirical probabilities to predict future states.

2. Comprehensive Theory

A standard (first-order) Markov Chain operates on the principle that the probability of transitioning to the next state depends only on the current state. Mathematically, this is expressed as:

\[P(X_t \mid X_{t-1}, X_{t-2}, \dots, X_0) = P(X_t \mid X_{t-1})\]

However, in many real-world scenarios (like natural language processing, weather forecasting, or complex system modeling), the immediate past is not enough to accurately predict the future. A Higher-Order Markov Chain extends this concept. In a second-order Markov Chain, the next state depends on the two most recently observed states. The mathematical formulation updates to:

\[P(X_t \mid X_{t-1}, X_{t-2}, \dots, X_0) = P(X_t \mid X_{t-1}, X_{t-2})\]

To simulate this computationally, we must analyze sequences of data in “windows” of size 3: the two previous states (the “history”) and the resulting next state (the “target”). By counting the frequencies of these triplets across a large dataset, we can derive the empirical transition probabilities.

3. Program Logic

This program is implemented from scratch without advanced statistical libraries, relying entirely on Python’s built-in random module and dictionary data structures.

  • Synthetic Data Generation: Because we lack real-world historical data, the program randomly generates 500 synthetic sequences, each consisting of 10 weather states (Sunny, Cloudy, or Rainy).
  • Triplet Frequency Counting: It iterates through every generated sequence using a sliding window approach (i-2, i-1, i). It builds a dictionary named counts where the key is a tuple representing the state transition (state1, state2, next_state) and the value is the number of times that specific sequence occurred.
  • Probability Calculation: To find the probability of \(X_t\) given \((X_{t-2}, X_{t-1})\), the program loops through all possible pairs of state1 and state2. It sums up the total occurrences of all transitions originating from that specific pair. It then divides the count of each specific target state by this total sum to yield a normalized probability (between 0 and 1).
  • Probabilistic Prediction: Finally, the program demonstrates how to make a prediction. Given a history of ("Sunny", "Cloudy"), it extracts the raw frequency counts for all possible next states. It passes these counts as weights into the random.choices() function, which randomly selects the next state but heavily biases the selection toward states with historically higher probabilities.

PRACTICAL 5A: Calculate Pearson Correlation Coefficient

1. Aim

To calculate the Pearson Correlation Coefficient between hours studied and marks obtained from first principles, verify it using built-in libraries, and visualize the relationship.

2. Comprehensive Theory

Karl Pearson's Coefficient of Correlation (denoted as \(r\)) is a statistical measure that quantifies the strength and direction of the linear relationship between two continuous variables, \(X\) and \(Y\).

The value of \(r\) always falls between \(-1\) and \(+1\):

  • \(r = 1\): Perfect positive linear correlation (as \(X\) increases, \(Y\) increases proportionally).
  • \(r = -1\): Perfect negative linear correlation (as \(X\) increases, \(Y\) decreases proportionally).
  • \(r = 0\): No linear correlation.

The mathematical formula is the covariance of the two variables divided by the product of their standard deviations. For a sample, it is calculated as:

\[r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2} \sqrt{\sum (y_i - \bar{y})^2}}\]

Where:

  • \(x_i, y_i\) are individual sample points.
  • \(\bar{x}, \bar{y}\) are the sample means of \(X\) and \(Y\).

3. Program Logic

The program implements the formula using NumPy's vectorized operations, which makes the mathematical execution clean and efficient without needing explicit for loops.

  • Mean and Deviations: The function first calculates the means \(\bar{x}\) and \(\bar{y}\). By subtracting the mean from the arrays (x - x_mean), NumPy automatically broadcasts the subtraction across all elements, creating arrays of deviations.
  • Numerator and Denominator: The numerator is calculated by multiplying the \(X\) deviations by the \(Y\) deviations and summing them (np.sum). The denominator squares the deviations, sums them, and takes their square roots.
  • Verification and Interpretation: The program computes the manual result and instantly cross-verifies it against NumPy’s highly optimized np.corrcoef function. It then uses an if-elif block to evaluate the absolute value of \(r\) to categorize the relationship strength (weak, moderate, strong) and its sign to determine direction.
  • Visualization: Finally, the program uses matplotlib.pyplot to generate a scatter plot of the raw data. It utilizes np.polyfit(..., 1) to calculate the slope and intercept of the degree-1 polynomial (the line of best fit) and overlays this trendline on the scatter plot.

PRACTICAL 5D: Multiple Linear Regression

1. Aim

To predict the price of a house using multiple linear regression by generating a synthetic dataset, training a model via the scikit-learn library, and evaluating its performance through statistical metrics and residual visualizations.

2. Comprehensive Theory

Multiple Linear Regression (MLR) is an extension of simple linear regression that models the relationship between a single continuous dependent variable (target) and two or more independent variables (features).

The general equation for a multiple linear regression model is:

\[Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \dots + \beta_p X_p + \epsilon\]

Where:

  • \(Y\) = Predicted target variable (e.g., House Price).
  • \(X_1, X_2, \dots, X_p\) = Independent feature variables (e.g., Size, Bedrooms, Distance).
  • \(\beta_0\) = The y-intercept (the expected value of \(Y\) when all \(X=0\)).
  • \(\beta_1, \dots, \beta_p\) = The coefficients (the average change in \(Y\) for a one-unit change in \(X_i\), assuming all other variables are held constant).
  • \(\epsilon\) = The error term or residual (unexplained variance).

Model Evaluation Metrics:

  • Mean Absolute Error (MAE): The average absolute difference between actual and predicted values. It represents the average error in the same units as the target variable.
  • Mean Squared Error (MSE): The average of the squared differences. It heavily penalizes larger errors.
  • R-squared (\(R^2\)): The Coefficient of Determination. It represents the proportion of the variance in the dependent variable that is predictable from the independent variables. An \(R^2\) close to \(1.0\) indicates an excellent fit.

PRACTICAL 6A: Lagrange Interpolation

1. Aim

To interpolate the value of y at a given x using Lagrange Interpolation, implementing the formula from first principles and visualizing the resulting polynomial curve.

2. Comprehensive Theory

Interpolation is the mathematical process of estimating unknown values that fall within the range of a discrete set of known data points. It is highly useful in numerical analysis to construct a continuous function from sampled data.

Lagrange Interpolation is a specific technique that finds a single polynomial \(P(x)\) of degree \(\le (n-1)\) that passes exactly through \(n\) given data points: \((x_0, y_0), (x_1, y_1), \dots, (x_{n-1}, y_{n-1})\).

The polynomial is given by the formula:

\[P(x) = \sum_{i=0}^{n-1} y_i L_i(x)\]

Where \(L_i(x)\) represents the Lagrange Basis Polynomials, defined as:

\[L_i(x) = \prod_{\substack{j=0 \\ j \neq i}}^{n-1} \frac{x - x_j}{x_i - x_j}\]

The mathematical trick of this basis polynomial is that \(L_i(x_i) = 1\), and \(L_i(x_j) = 0\) for all \(j \neq i\). This guarantees that at every known \(x_i\), the total polynomial exactly equals the corresponding \(y_i\), ensuring the curve passes perfectly through every given point.

3. Program Logic

The program implements the Lagrange polynomial computationally using fundamental nested loops and arrays.

  • Target Computation: The custom lagrange_interpolation function calculates the estimated \(y\) value. It initializes a total sum to \(0\).

  • Nested Iteration:

  • The outer loop i selects the current data point. It initializes a term variable directly to \(y_i\).

  • The inner loop j constructs the basis polynomial product. If \(j \neq i\), it multiplies the term by the fraction \(\frac{x - x_j}{x_i - x_j}\).

  • After the inner loop finishes, the fully multiplied term is added to the total.

  • Vectorized Evaluation: Because of NumPy’s broadcasting capabilities, the x_val parameter passed to the function can be a single number (like 2.5) OR an entire array of numbers. When an array of 200 smoothly spaced points (np.linspace) is passed, the function returns a complete array of \(y\) values, generating the data needed to plot the smooth polynomial curve.

  • Visualization: The code plots the raw data points in red, overlays the smooth calculated polynomial curve in blue, and marks the specific estimated point (\(x=2.5\)) with a prominent green “x”.

    n = len(x_points)

        # Basis polynomial L_i(x)

PRACTICAL 6B: Newton’s Divided-Difference Interpolation

1. Aim

To interpolate the value of y at a given x using Newton's Divided-Difference Interpolation, by algorithmically constructing the divided difference table from scratch and visualizing the resulting polynomial.

2. Comprehensive Theory

Newton's Divided-Difference Interpolation is a popular method for constructing interpolation polynomials. Unlike Lagrange interpolation, where the entire polynomial must be recalculated from scratch if a new data point is added, Newton’s method builds the polynomial sequentially.

For \(n\) data points \((x_0, y_0), \dots, (x_{n-1}, y_{n-1})\), the Newton polynomial is written as:

\[P(x) = f[x_0] + f[x_0, x_1](x - x_0) + f[x_0, x_1, x_2](x - x_0)(x - x_1) + \dots\]

The coefficients \(f[\dots]\) are the Divided Differences, which are calculated recursively and stored in a triangular table:

  • \(0^{th}\) divided difference: \(f[x_i] = y_i\)
  • \(1^{st}\) divided difference: \(f[x_i, x_{i+1}] = \frac{f[x_{i+1}] - f[x_i]}{x_{i+1} - x_i}\)
  • \(k^{th}\) divided difference: \(f[x_i, \dots, x_{i+k}] = \frac{f[x_{i+1}, \dots, x_{i+k}] - f[x_i, \dots, x_{i+k-1}]}{x_{i+k} - x_i}\)

The coefficients used to construct the final polynomial are always found in the very top row of this generated table.

3. Program Logic

The program isolates the mathematical steps into two distinct, highly efficient functions.

  • Table Construction (divided_diff): The program initializes an \(n \times n\) nested list (a 2D matrix) filled with zeros. It populates the first column with the raw \(y\) values. Using a nested loop (outer loop j for columns, inner loop i for rows), it applies the recursive divided difference formula, subtracting adjacent cells from the previous column and dividing by the span of \(x\).
  • Polynomial Evaluation (newton_predict): To predict a value, the function extracts the coefficients strictly from table[0][i] (the top row). It uses a for loop to continuously multiply the \((x - x_i)\) factors together into a term variable, multiplying that term by the respective table coefficient, and accumulating the result.
  • Algorithmic Efficiency: Because the divided_diff table is built only once globally, the plotting phase simply evaluates newton_predict 100 times using a list comprehension. This drastically reduces computational overhead compared to recalculating the coefficients for every single point.

import matplotlib.pyplot as plt
import numpy as np


# 1. Build the Divided-Difference Table
def divided_diff(x, y):
    n = len(y)
    # n x n grid initialized with zeros
    table = [[0.0] * n for _ in range(n)]

    # First column is just the y values
    for i in range(n):
        table[i][0] = y[i]

    # Fill remaining columns using the divided difference formula
    for j in range(1, n):  # column (order of difference)
        for i in range(n - j):  # row
            table[i][j] = (table[i + 1][j - 1] - table[i][j - 1]) / (
                x[i + j] - x[i]
            )

    return table


# 2. Evaluate Newton's Polynomial at a specific target value
def newton_predict(x, table, target):
    n = len(x)
    result = table[0][0]  # First term: f[x0]
    term = 1.0  # Accumulates (x - x0)(x - x1)...

    for i in range(1, n):
        term *= target - x[i - 1]
        result += table[0][i] * term

    return result


# --- Main Program ---
x_pts = [1, 2, 3, 4]
y_pts = [1, 4, 9, 16]

# Build table once
table = divided_diff(x_pts, y_pts)

# Print table
print("Divided-Difference Table:")
for row in table:
    print(["%.4f" % val for val in row])

# Predict at a single point
target = 2.5
prediction = newton_predict(x_pts, table, target)
print(f"\nInterpolated value at x = {target}: {prediction:.4f}")

# Plotting
# Generates smooth x values
x_curve = np.linspace(min(x_pts), max(x_pts), 100)
# Uses the precomputed table directly (no recomputing)
y_curve = [newton_predict(x_pts, table, xi) for xi in x_curve]

plt.figure(figsize=(8, 5))
plt.scatter(x_pts, y_pts, color="red", zorder=5, label="Known Points")
plt.plot(x_curve, y_curve, color="purple", label="Newton Curve")
plt.scatter(
    target,
    prediction,
    color="green",
    marker="x",
    s=100,
    zorder=5,
    label=f"Interpolated ({target})",
)

plt.title("Newton Divided-Difference Interpolation")
plt.xlabel("x")
plt.ylabel("y")
plt.legend()
plt.grid(alpha=0.3)
plt.show()

    n ← LENGTH(y)
    table ← n × n matrix initialized to 0.0

    FOR i FROM 0 TO n - 1 DO
        table[i][0] ← y[i]
    END FOR

    FOR j FROM 1 TO n - 1 DO
        FOR i FROM 0 TO n - 1 - j DO
            table[i][j] ← (table[i + 1][j - 1] - table[i][j - 1]) / (x[i + j] - x[i])
        END FOR
    END FOR

    RETURN table
END FUNCTION

FUNCTION newton_predict(x, table, target):
    n ← LENGTH(x)
    result ← table[0][0]
    term ← 1.0

    FOR i FROM 1 TO n - 1 DO
        term ← term * (target - x[i - 1])
        result ← result + table[0][i] * term
    END FOR

    RETURN result
